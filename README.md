# Федерация хоккея Республики Мордовия — прототип

Многостраничный прототип официального информационного портала.

## Страницы
- Главная
- Матчи
- Турниры
- Таблицы
- Команды + отдельные страницы каждой команды
- Новости
- Мероприятия
- Федерация
- Контакты

## Запуск
Можно просто открыть `index.html` локально.
Для GitHub Pages загрузите содержимое репозитория в новый репозиторий и включите Pages для ветки `main`, папка `/root`.

На финальном этапе заменим демо-тексты, фотографии, логотипы команд, расписание и статистику на реальные данные.
