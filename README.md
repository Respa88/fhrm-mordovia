# ФХРМ — прототип v3

Светлый современный портал Федерации хоккея Республики Мордовия.

Логика структуры вдохновлена современными федерационными спортивными порталами: новости, календарь, таблицы, турниры, клубы, статистика, СДК, документы, медиа, партнёры и отдельные страницы матчей.

Важно: все тексты, результаты, статистика, фотографии и даты являются демонстрационными и предназначены для презентации скелета проекта.

Все логотипы и концепт-изображения встроены непосредственно в `script.js` как data URI. Отдельная папка assets не нужна.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
