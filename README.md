# ФХРМ — прототип 2026

Светлая версия официального портала Федерации хоккея Республики Мордовия.

## Что изменено
- светлая строгая визуальная система;
- цвета Мордовии: тёмно-красный / белый / тёмно-синий;
- крупная современная типографика;
- отдельные страницы: матчи, турниры, таблицы, команды, новости, события, федерация, контакты;
- 6 команд: Сияжар, Слобода, Викинг, Совы, Метеор, Локомотив;
- президент: Манин Сергей Владимирович;
- ATRINIKA как партнёр с ссылкой на https://atrinika.pro/;
- логотип федерации, флаг и логотип ATRINIKA встроены прямо в JavaScript как data URI — папка assets не нужна;
- временные хоккейные визуалы созданы локально для прототипа и позже могут быть заменены на реальные фото.
